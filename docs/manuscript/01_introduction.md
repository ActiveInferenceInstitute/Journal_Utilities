# Introduction

Transcripts are useful as research inputs only if a reader can trace a record to a source and identify what changed during preparation. Video metadata, downloaded or generated captions, speaker attribution and later language conversion are distinct observations. A publishing process that combines them needs stable source identifiers and explicit retention rules so a later rebuild can be evaluated.

Journal Utilities provides the processing code for this relationship. The companion corpus owns public records and schema. The present study separates repository architecture from empirical accuracy and documents the crossing between the two projects.
